**One wording for a missing `sessionId`** — tools that take only a session id
rejected an omitted one with two different messages depending on which tool you
called (`Missing required sessionId` from `close_debug_session`,
`attach_to_process`, `detach_from_process`, the step tools, `continue_execution`,
`list_threads`, `get_stack_trace`, `expose_session` and `unexpose_session`, but
`Missing required parameter: sessionId` from `list_breakpoints`,
`remove_breakpoint`, `clear_breakpoints` and `restart_debugging`); they all now
say `Missing required parameter: sessionId`. Tools that require several
parameters keep their own `Missing required parameters` message (#568)
