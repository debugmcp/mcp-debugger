**Toolchain checks are cheaper and more reliable** — the checks behind `list_supported_languages`, the launch gate and `mcp-debugger doctor` now share one version probe that runs the tool directly (no shell), reads its output only after the pipes have drained, and stops it after 10 s; before this the Go, Python and C/C++ checks read output when the process exited, so a version printed late could be lost, and several had no time limit. Fewer duplicate runs: Java ran `java -version` twice (two JVM starts) and now runs it once, Python imported debugpy twice on the chosen interpreter and now does it once, Go runs `dlv version` and `dlv dap --help` side by side. Rust's `cargo` builds, test runs and metadata reads no longer go through a shell, which joined the arguments unquoted and broke on a project path with spaces (#969)
