**`outputTail` on a non-zero exit drops adapter housekeeping and preserves leading crash causes** — `outputTail` now quotes the last 8 lines of the program's own output in arrival order across streams (joining partial chunks per stream, ending lines after 8,192-character truncated chunks, excluding adapter `console` lines and anchored Node inspector / JVM JDWP banners, and reclaiming Dart `dart:developer` `log()` and test-result `console` lines). When all 8 lines fall inside one `stderr` block longer than 8 lines — or when a native runtime fatal-error header (`libcob: … error: …`, `terminate called …`) sits above the last 8 lines, including on Linux/macOS where CodeLLDB merges pty streams into `stdout` — `outputTail` quotes that head line and the 3 after it, `"... (N lines omitted)"`, and the last 3 lines; Python keeps its plain last 8 lines so both the user's frames and the trailing exception stay visible (#1277)
