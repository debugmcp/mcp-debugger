**A rejected `MCP_HTTP_*` setting is named in the log; its value is not** — an invalid `MCP_HTTP_STALE_SESSION_MS`, `MCP_HTTP_STREAM_LOST_SESSION_MS` or `MCP_HTTP_STALE_SWEEP_INTERVAL_MS` used to be quoted in the warning that rejects it, so a secret pasted into the wrong variable, or a value with a line break in it, was copied into the server log. The warning now names the variable and the default in force, as the debug-session idle settings already do (#1025)
