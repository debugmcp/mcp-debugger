**The pytest-preset `pytest.raises` rule is keyed to pydevd's implementation, not the Python version** — an exception `pytest.raises` expects never pauses under pydevd's `sys.monitoring` path, which needs Python 3.12+ *and* debugpy 1.8.6 or later; an older debugpy on 3.12 (Ubuntu 24.04's packaged 1.8.0, say) traces frames and pauses once at the raise, the same as 3.11. The docs said "3.12+", and the end-to-end test gated on the Python minor version, so it failed on such a host; the test now asks pydevd which implementation it runs (`PYDEVD_USE_SYS_MONITORING`, env override included) and the docs name both conditions. The COBOL smoke test also clears only the host's own build-cache root under `examples/cobol/.debug-mcp` (one root per host/container, #1035) instead of the whole cache, which the Docker attach lane writes as root through the bind mount (EACCES); that lane now hands the shared cache back to the host user when it ends.
