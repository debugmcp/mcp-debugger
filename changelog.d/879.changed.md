A Dart `step_over` now leaves the line. The SDK debug adapter stops once per token position, so a line like `final answer = counter.value + 2;` took three `step_over` calls, each answering "Stepped over" while still on the same line. mcp-debugger now repeats the DAP step while it lands on the line it left, in the same stack frame, up to eight times. The answer says how many steps it took, for example "Stepped over in 3 steps …". A breakpoint or exception on that line still ends the step at once. So does a landing in another frame, such as a recursive call returning to its caller on the same line (#879)
