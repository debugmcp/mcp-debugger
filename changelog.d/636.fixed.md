**Ruby function breakpoints are rejected up front instead of silently never binding** — rdbg's initialize response advertises `supportsFunctionBreakpoints`, but the debug gem's DAP handler (verified against debug 1.11.0) acknowledges `setFunctionBreakpoints` and does nothing, so a Ruby function breakpoint was accepted with a vague "support is unknown" warning and then never bound. The Ruby policy now pins the capability off — `set_breakpoint {function}` fails immediately with `UnsupportedFeatureError` for Ruby — and the adapter's self-reported capabilities agree. (#636)
