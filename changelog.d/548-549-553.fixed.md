**Inspection fallbacks find useful locals and explain frameless threads** — JavaScript local inspection now tries Closure and Module/Script scopes on the same frame before leaving it (Global stays reserved for top-level frames with no Local scope, so Node's globals are never reported as locals); Ruby hides rdbg's `%self` pseudo-variable unless special variables are requested, so a native `[C]` frame counts as empty and inspection walks down to the real Ruby frame; and `get_stack_trace` identifies the inspected thread and suggests a frame-bearing alternative when an explicitly requested thread has no frames (#548, #549, #553)
