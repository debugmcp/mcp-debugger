**A second MCP conformance lane for the 2026-07-28 revision.** `node scripts/mcp-conformance.mjs --era 2026-07-28` runs the protocol org's conformance suite on its 0.2 line (`@modelcontextprotocol/conformance@0.2.0-alpha.12`, the line the SDKs run) with `--requirements 2026-07-28` — everything the revision requires of a server — against a local `http` server, and judges the run under `scripts/conformance/expected-failures-2026-07-28.yaml`: the scenarios, or single checks, that drive the suite's own reference fixtures (the "everything server" tools, resources and prompts this server does not have), each with the fixture it needs named beside it. An unlisted failure fails the lane; so does a listed entry that passes, so the baseline only shrinks. CI runs it as `mcp-conformance-2026`, required in the test summary beside the 2025-11-25 lane, which is unchanged. Measuring the lane also found that `resources/templates/list` answered "Method not found": a server advertising the resources capability must answer it, so both eras now answer an empty list.
