**A JavaScript launch forwards every `adapterLaunchConfig` key it does not derive itself** — the launch transform used to emit a fixed set of keys, so js-debug options such as `trace`, `__workspaceFolder`, `perScriptSourcemaps`, `timeouts` or `sourceMapPathOverrides` passed through `adapterLaunchConfig` were silently dropped (attach has forwarded unrecognised keys since #466). They now reach js-debug as-is, the forwarded names are logged, and a caller `resolveSourceMapLocations` — including an explicit `null` — wins over the launch default, as it already did on attach. Keys the transform derives (`env`, `skipFiles`, `smartStep`, `outFiles`, the runtime selection) keep winning (#703)
