**`detach_from_process` no longer says a launched program is still running after it has ended it.** A plain detach on a session that launched its program answered `Detached from process (process still running)` and the program was gone, in every adapter (the worker follows a launch session's disconnect with a terminating one and a tree kill). A session owns a program it launched and borrows one it attached to; ending a session ends what it owns. So that detach is now refused before anything is touched: `success: false`, the session unchanged, and a message that names what to do (`close_debug_session` or `terminateProcess: true` to end the program; start it outside the debugger and `attach_to_process` to keep it running afterwards). Attach sessions detach as before. (#1151)
