**A Python or Ruby attach to a debug server that ends the handshake itself names the endpoint.** When the server at the caller's port sent DAP `terminated` and closed during the handshake, the answer was `Proxy exited during initialization. Code: 0…` followed by ten lines of worker log output; when it refused a configuration request in its own words, the answer carried the words and no endpoint. Both now say what was dialed and that nothing was started for the attach: `host:port ended the debug session during the DAP handshake: it sent "terminated" and the connection closed. …`, and `Error in DAP sequence: … [direct connect to host:port; no adapter process was started]`. The parent words these itself from the endpoint the worker reports before it dials, so the answer no longer depends on which of the worker's messages arrives first.
