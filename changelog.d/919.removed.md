**`IDebugAdapter.getDefaultAttachConfig` is removed from `@debugmcp/shared`.** The host never called it, so the values the eight adapters returned (Ruby's and CodeLLDB's `stopOnEntry: true`, Dart's `timeout: 30000`) never reached an attach; the defaults that apply live in each adapter's `transformAttachConfig`. Adapters that still define the method keep compiling (extra members are fine); a caller of it would not, and none is known. Attach behaviour is unchanged (#919)
