**js-debug moves to v1.140.0** (from v1.112.0; the engine behind JavaScript, Node.js and TypeScript debugging). Upstream changes between the tags include honouring an explicit pause while smart-stepping and restored attach retries on Node 24.20; the node launch options are unchanged. The vendor script now re-vendors whenever the vendored tree names another version than the pin — a bumped pin used to be invisible on any checkout that had vendored once, and in a Docker image built from one — and verifies the extracted server file against the manifest's derived digest, which was recorded but never checked. Refs #1049.
