**JavaScript block-scoped bindings are visible as locals** — a `let`/`const` declared inside a `for` body, an `if` block or a `catch (e)` clause lives in a js-debug scope named exactly `Block` (or `Catch Block`/`With Block`), while mcp-debugger only recognised the `Block:<label>` form some builds emit — so `get_local_variables` at a breakpoint inside a loop silently omitted the loop variable. Block scopes are now merged ahead of the function's own `Local` scope, innermost first, matching JavaScript's shadowing order; the response still names the `Local` scope and adds no note, because the frame's own locals reached the caller. Global remains reserved for frames with no local or block scope at all (#558)
