**Self-debugging starts with a complete tool inventory and a working nested server** — requests to
the development proxy now wait while the backend is starting or restarting, so the first tool
listing includes the debugging tools and a call issued during a restart reaches the new backend
instead of being refused with a hint that would queue a second restart. The wait is bounded by
`DEV_PROXY_DISCOVERY_WAIT_MS` (15 seconds by default), recovery tools stay callable throughout, and
a backend that dies at spawn ends the wait immediately rather than holding it open for the health
timeout. The bundled CLI scopes its internal startup suppression flag to the core import and
restores the caller's environment before launching adapters or debuggees (#716, #717).
