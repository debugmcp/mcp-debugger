**A Go package directory as `scriptPath` launches, and a failed build says why** — a directory target defaulted its working directory to the directory's parent, so `go build` ran under the parent's own `go.mod` and failed ("main module … does not contain package …"), and without an explicit `mode` the directory was treated as a binary (`dlv exec`: "not an executable file"). A directory is now its own cwd and a `debug` target. A launch that fails after the proxy started also quotes the last lines the adapter produced before the failure — the compiler's error behind Delve's "Build error: Check the debug console for details." — after the adapter's own message, so the agent does not need a second call to `get_output` to learn why (#1036)
