**`http` mode answers an unknown `Mcp-Session-Id` with 404** — a request naming a session the server no longer knows (after a restart, or after the stale-session sweep reaped it) was answered 400, which a Streamable HTTP client treats as a dead end; the spec's 404 (`-32001 Session not found`, the SDK transport's own answer) lets a client that follows the spec, Claude Code included, start a new session by itself instead of needing a manual reconnect, and a request with no session id that is not an `initialize` still gets 400 (#1017; relates to #337)
