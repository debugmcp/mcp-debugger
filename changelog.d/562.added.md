**`typecheck` and `typecheck:tests` scripts that actually check something** — the root
`tsc -p tsconfig.json` is a solution-style config with `"files": []`, so it compiled and
verified nothing, and `tsconfig.spec.json` (sources + tests) was unrunnable because its
`paths` had no `baseUrl`. `pnpm run typecheck` now type-checks `src/` and every
`packages/*/src` in one build-free pass, and `pnpm run typecheck:tests` holds the test
suite to a per-file error baseline (`tests/typecheck-baseline.json`) so new type errors in
tests fail CI and pre-push while the existing backlog is paid down incrementally (#562)
