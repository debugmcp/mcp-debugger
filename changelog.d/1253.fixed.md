**JavaScript test runners launched from node_modules now find the project's tests by default.**
Without an explicit working directory, the launch uses the folder containing the outermost
`node_modules`, including nested pnpm paths, instead of the runner's package directory. The
launch notice appears once, names the absolute directory used and explains the `dapLaunchArgs.cwd`
override and `adapterLaunchConfig.cwd` precedence. Relative runner paths resolve against the
launcher's original working directory before selecting the default, preserving the intended
program. Explicit working directories and programs outside `node_modules` keep their existing
behavior (#1253)
