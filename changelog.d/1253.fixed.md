**JavaScript test runners launched from node_modules now find the project's tests by default.**
Without an explicit working directory, the launch uses the folder containing the outermost
`node_modules`, including nested pnpm paths, instead of the runner's package directory. The
launch notice names the directory used and the `dapLaunchArgs.cwd` override; explicit working
directories and programs outside `node_modules` keep their existing behavior (#1253)
