**A child session's proxy-log resource reads its tree's log.** `resources/list` offered `debug://sessions/<child>/proxy-log` for every child session and reading it returned nothing: one worker serves a tree and writes one log, named after the root, and the reader built the path from the child's own id. A child's proxy-log resource, and the log pointers of a child's failure, now name the tree's file (#1222).
