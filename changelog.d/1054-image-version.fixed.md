**The Docker image reports its release version** — `docker run debugmcp/mcp-debugger doctor` printed `mcp-debugger doctor 0.0.0`, and `--version` said `0.0.0`, because the bundle looked for a `package.json` beside `dist/bundle.cjs` that the image does not carry. The build now bakes the version into the bundle, and the server's MCP `initialize` answer (`serverInfo.version`) carries the release version on every transport instead of the literal `0.1.0` it had always sent. Closes #1054.
