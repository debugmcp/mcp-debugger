**The deprecated `sse` command is removed** — the legacy HTTP+SSE transport (`mcp-debugger sse`, the `/sse` endpoint) is gone; use `http` (Streamable HTTP, the `/mcp` endpoint), which takes the same `--port`, `--bind` and `--allowed-host` options. Gone with it: the dev proxy's `sse` backend mode (`DEV_PROXY_BACKEND_TRANSPORT` now accepts `http` or `stdio` and refuses any other value by name, where an unrecognised value used to fall through to the legacy client silently), the PyPI launcher's `sse` mode choice, and the `@modelcontextprotocol/server-legacy` dependency. Closes #1078.
