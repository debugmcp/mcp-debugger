**The `http` endpoint now validates `Origin`, so a web page cannot drive a local debugger from the user's browser** — the Host check (DNS-rebinding protection) was the only guard, and CORS answered every origin with `Access-Control-Allow-Origin: *`, so `fetch('http://localhost:3001/mcp')` from any site passed the Host check and could initialize a session and call every tool. A browser request's `Origin` hostname must now be on the same allowlist as `Host` (loopback by default, extended with `--allowed-host` / `MCP_HTTP_ALLOWED_HOSTS`); requests without an `Origin` — every non-browser client — are unaffected, the opaque `null` origin is refused, and the validated origin is echoed in `Access-Control-Allow-Origin` (with `Vary: Origin`) instead of `*` (#677)
