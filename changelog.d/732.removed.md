**`DEBUG_MCP_SKIP_AUTO_START` is gone** — the env var the bundled CLI set and restored around its import of the server entry no longer exists, and a `DEBUG_MCP_SKIP_AUTO_START=1` inherited from the environment no longer stops `dist/index.js` from starting its server. Nothing else changes for users: `main()` now lives in a module with no side effects (`src/main.ts`) that the npm bundle imports directly instead of importing `src/index.ts` behind the flag, and the console silencing and argv cleanup both entries need moved to one prologue module (`src/cli/entry-prologue.ts`) that each evaluates first (#732)
