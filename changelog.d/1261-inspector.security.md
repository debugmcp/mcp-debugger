**An attach by processId no longer leaves an unauthenticated Node.js inspector listening in the target** — the inspector `attach_to_process { processId }` opened stayed open on `127.0.0.1:9229` after the session ended, and any local process could connect to it and run code in the target for as long as the target ran. It is now closed when the session that opened it detaches or closes, and the answers say so; like any inspector it is open while the session lasts, and it stays open if the server is killed before its sessions end (#1261)
