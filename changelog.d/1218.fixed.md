**Document measured logpoint costs instead of promising unpenalized speed or production safety** — the docs, shipped skill text, and `set_breakpoint` tool description now state that logpoints do not pause execution but cost time on every hit, with measured per-engine costs (from 24.7 µs in Python to 4.9 ms in Dart, plus whole-function slowdowns in Python, JavaScript, and Dart) and practical hit-rate limits. The Python guide and skill reference also note that queued logpoint lines are silently lost on program exit when hits outrun debugpy delivery (#1265), and adapter lists now reflect all seven supporting adapters (#1218).
