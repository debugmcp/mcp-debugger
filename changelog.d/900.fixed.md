**A JavaScript pause that lands between event-loop dispatches says so** — js-debug's pause on an idle Node server lands on an `<anonymous>` frame at `<unknown_source>:1` with no scopes; it read as program code, so `attach_to_process` and `pause_execution` answered a bare location and `get_stack_trace` a one-frame stack with nothing said. A frame with no source at all is internal now whatever its line: the frame stays visible when it is the only one, `get_stack_trace` reports `noProgramFrame: true`, and the attach, pause and stack answers carry the note `No program frame is active … continue_execution and trigger activity, or set a breakpoint` (#900)
