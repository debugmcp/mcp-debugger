**The test-typing ratchet gains `--allow-improvement`, and says how to repair a baseline it cannot read** — a dependency bump that makes the test suite type-*cleaner* (a better `@types` package, say) used to fail its own CI check: the ratchet fails on a decrease so the recorded baseline cannot silently go stale, and Dependabot has no way to commit the refresh. CI now passes `--allow-improvement` for `dependabot[bot]` only, which warns on a decrease and still fails on any increase or newly erroring file; pre-push and human PRs stay strict, and the flag is refused alongside `--update`. Separately, all four "this baseline is unreadable" errors (invalid JSON, wrong shape, a bad per-file count, a path outside the test trees) now name the remedy the fourth already did — delete `tests/typecheck-baseline.json`, then re-record it with `pnpm run typecheck:tests:update` — because `--update` reads the baseline before writing one, so a corrupt file blocks its own repair (#581)
