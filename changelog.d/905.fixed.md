**`create_debug_session`'s attach shortcut takes everything `attach_to_process` does** — `processId`, `sourcePaths`, `justMyCode` and `breakOnExceptions` were dropped silently, and a `processId` without a `port` did not trigger the attach at all. Both entry points now build one request: `port`, `processId` or an `adapterConfig` naming a debugger URI (`vmServiceUri`, `websocketAddress`, `vmServiceInfoFile`) attaches in the same call (`host` alone still does not), an invalid `breakOnExceptions` is refused before the session exists, and the shortcut no longer forces `host: localhost` / `timeout: 30000` — the adapter's defaults apply, as for `attach_to_process` (a forced 30 s connect timeout on js-debug out-waited the 20 s verify window). The attach docs also no longer claim that `stopOnEntry: false` skips thread verification; it skips only the post-attach pause (#905)
