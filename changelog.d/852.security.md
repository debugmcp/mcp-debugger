**Debuggee output is no longer copied verbatim into the server and proxy logs at the default level** — every DAP `output` event was written with its full body, at `info`, to the per-process server log (twice) and to the per-session proxy log, two files under the temp directory that outlive the session; a program that printed a credential left it there in plain text while `get_output` masked the same value, and the logs grew with everything a chatty program printed (one 480-line debuggee: 1.3 MB of log). Those records now carry the output's category and length only; the one verbatim copy is at `debug` level and masked like `get_output` is. Other event bodies (`process`, `stopped`, …) are logged after the same sanitization as request payloads — environment blocks counted, token-shaped values masked (#852)
