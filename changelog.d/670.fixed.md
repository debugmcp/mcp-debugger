**The `http` transport's 10 MB JSON body limit is actually in force, and parser failures answer as JSON-RPC** — the app was built with the SDK's `createMcpExpressApp()`, which installs its own `express.json()` at body-parser's 100 KB default ahead of everything else, so the `express.json({ limit: '10mb' })` registered afterwards never parsed anything: any request over 100 KB (a large `evaluate_expression`, a long `expectedContent`, a big batch) got a 413 carrying Express's HTML error page. The app is now built directly — Host allowlist first, then CORS, then one 10 MB parser — and an oversize or malformed body answers `413`/`400` in the JSON-RPC error shape (`-32600` / `-32700`) instead of HTML (#670)
