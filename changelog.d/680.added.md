**`--bind <address>` / `MCP_HTTP_BIND` choose the interface the `http` and `sse` transports listen on, and `/health` reports it** — precedence is the flag, then the variable, then `127.0.0.1`. `localhost` is normalized to `127.0.0.1` (Node would bind only the first resolved address family and refuse `127.0.0.1` clients); only IP literals are accepted, and an unusable value refuses to start by name, like `--allowed-host`. A non-loopback bind logs a warning naming the flag and the fact that the Host/Origin allowlist stops browsers, not direct clients; the startup line prints a URL a client on the machine can open. `GET /health` gains `listening: { address, port }`. The PyPI launcher forwards `--bind` to the npx-run server too (it used to warn that the flag was Docker-only) (#680)
