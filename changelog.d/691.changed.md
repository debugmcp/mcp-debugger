**`IDapClient` now describes its implementations** — `on`/`off`/`once`/`removeAllListeners` return `this` (every implementation is an `EventEmitter`) and `sendRequest` is typed to `DebugProtocol.Response` like `MinimalDapClient`, so the production factory no longer needs an `as any` and test doubles are checked against the interface instead of widened past it. The app-local duplicates of the shared external-dependency interfaces (`src/interfaces/external-dependencies.ts`, and the `IProcess*` copies in `src/interfaces/process-interfaces.ts`) are gone — `@debugmcp/shared` is the single declaration (#691, #692)
