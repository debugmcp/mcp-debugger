**The JavaScript guide says where V8's fix for the steps it loses stands.** V8 16.0 fixes the lost step out of a function that returns through `try … finally` (V8 issue 569814973); no Node release has it yet. On a runtime with it, these steps land in the caller, and a `step_over` off the end of a `finally` block first stops once more at the end of the `return`, with the value it returns. (#1173)
