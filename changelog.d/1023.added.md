**Streamable HTTP spec contract and the official conformance suite in CI** — the clauses of the Streamable HTTP transport (spec 2025-11-25) that this server answers with its own code — a missing `Mcp-Session-Id` is 400, an unknown, DELETEd or reaped one is 404, an invalid `Origin` is 403, an unsupported `MCP-Protocol-Version` is 400 — are pinned one case per clause against the real server over raw HTTP (`tests/integration/cli/http-spec-contract.test.ts`; the 404 cases are the ones #1017 fixed and nothing could have caught), and `scripts/mcp-conformance.mjs` runs the protocol org's `@modelcontextprotocol/conformance` suite (pinned) for its seven applicable scenarios against a local `http` server, as a CI lane on Linux (#1023)
