**Go: Delve 1.27's own `exited` event is supported alongside the older console-line exit status** — Delve 1.27 sends a DAP `exited` event with the program's exit code (go-delve/delve#4371). mcp-debugger already uses that event when it arrives, so `exitCode` in `list_debug_sessions` and the `start_debugging` run-to-completion summary is the same on every Delve. Older Delve, which is all a Go before 1.25 can run, is still covered by reading Delve's `Process N has exited with status S` console line. One visible difference: with Delve 1.27+ in debug mode, that console line no longer shows up in `get_output`, because Delve prints it only while the session is being torn down. CI now runs the Go integration tests on both Go 1.21 + dlv 1.24.2 and Go 1.27 + dlv 1.27.2 (#753)
