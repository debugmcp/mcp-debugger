**A launch under `breakOnExceptions: "none"` no longer promises a stop for an uncaught exception** — the "still running" answer of `start_debugging` and `wait_for_stop` said the program "will stop only for an uncaught exception the debugger catches by default" under every mode, which under `"none"` describes the filter the caller opted out of; the answer now names the mode and says a crash runs to the program's exit, so only the exit is promised (#1009)
