**Forwarded JavaScript attaches keep child processes runnable** — the default child-auto-attach setting now checks that the inspected target can read the debugger host's temporary storage and js-debug bootloader files before enabling injection. A localhost SSH or Kubernetes port forward can reach a different filesystem; injecting the host-only preload there made later Node children fail with `MODULE_NOT_FOUND`. If locality cannot be verified, attachment still succeeds with child auto-attach off and a warning. Explicit `adapterConfig.autoAttachChildProcesses` values are preserved; embedders bypassing the adapter transform default off without a locality check. The sibling-session lifecycle test also waits for both children's real breakpoints before closing one, avoiding a race with js-debug's initial pause.
