**`list_debug_sessions` no longer shows a running session the stop it already left** — the session model keeps `lastStop` across `continue_execution` and steps (the run-to-completion summary and the paused-state invariant depend on it), so a session that had been continued was listed as `"state": "running"` with a `lastStop` whose `description` still read `"Paused"`; the session listing now includes `lastStop` only for paused and terminal sessions, matching the tool description, and `get_stack_trace` omits `lastStop`/`stopReason` whenever the session is not paused (#720)
