**CodeLLDB moves to 1.12.3** (from 1.11.8; the engine behind Rust, C/C++ and COBOL debugging, now bundling LLDB 22.1.8). Upstream fixes users feel: inspecting an `Option<String>::None` local no longer hangs the variables request under rustc 1.93+ (the Rust smoke suite now pins it), `cwd` is honoured, and Windows paths with spaces work. CodeLLDB no longer installs its wildcard Rust synthetics provider by default, so the children `get_variables` shows for `Option`/`Vec`/`String` may render differently and the `[raw]` child on primitives is gone. The five `@debugmcp/codelldb-<platform>` packages republish at 1.12.3. Closes #1049.
