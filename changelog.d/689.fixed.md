**`http`/`sse` validate `--port` and announce the port the socket actually bound** — the option had no parser, so `-p abc` failed with Node's own `options.port should be >= 0 and < 65536. Received type number (NaN)` (naming an internal, not the flag, not the value typed), `-p 3001x` silently bound 3001 because `parseInt` stops at the first non-digit, and `-p 0` logged `listening on 127.0.0.1:0` while the OS-assigned port was visible only in `/health`. The value is now resolved the way `--bind` is: only an unsigned integer in 0-65535 is accepted, and anything else is refused by name before anything is announced or built — `--port value 'abc' is not a port number; give an integer 0-65535 (0 lets the OS choose). The server was not started.` The `listening on` / `endpoint available at` startup lines are emitted from the socket's `listening` event and carry the bound port, so `-p 0` prints the port a client can actually dial (#689)
