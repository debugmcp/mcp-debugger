**Changelog fragments replace hand-editing `CHANGELOG.md`** — every PR used to prepend its entry to the same line under `### Fixed`, so any two concurrent PRs conflicted regardless of what they actually changed: in the 2026-08-28 merge round, two of five PRs needed hand-resolution and `CHANGELOG.md` was the only conflicted source file in both. Each PR now adds its own `changelog.d/<issue>.<category>.md`, which makes the collision structurally impossible; `pnpm changelog:collate` folds them into `[Unreleased]` at release time, creating category headings in Keep a Changelog order so the section cannot grow the duplicate `### Fixed` block found in #462. A CI gate fails any PR that touches `src/`, `packages/`, or `tools/` without a fragment (test-only changes exempt automatically; `no-changelog` label to opt out), closing the "merged but undocumented" gap that left ~15 changes unrecorded (#546)
