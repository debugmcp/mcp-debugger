**Server logs no longer land inside the package tree** — the default log directory was derived from the module location (`<module-dir>/../../logs/`), which meant the bundled CLI wrote per-pid server logs into `packages/logs/` from a source checkout and into the consumer's `node_modules` tree when installed (a tree users expect to be disposable, and which can be mounted read-only). The default is now `os.tmpdir()/debug-mcp-server/`, the same OS temp state tree the per-session logs already use, on every host platform. `--log-file` and the container-mode `/app/logs` override behave exactly as before.
