**Forced C/C++ source rebuilds no longer destroy the previous executable** — a rebuild compiles to a staging file and only then replaces `.debug-mcp/<name>`; on Windows, when a running debuggee still locks that executable, the successful build is launched as a versioned artifact that later launches reuse (older unlocked versions are cleaned up). A launch transform that fails — a compile error, an invalid attach config — now aborts `start_debugging` with the adapter's error instead of silently starting the adapter with the untransformed config (#552)
