**No more focus-stealing console windows on Windows from spawned helper processes** — on Windows, a console program started by a process without a console window of its own gets a new window that takes focus. `mcp-debugger doctor`'s shell check and the orphan-process scan now pass `windowsHide: true` like the rest of the runtime. So do the build scripts, the dev proxy and the unit and integration tests, so a build or test run started from an agent, an IDE task or a git hook no longer flashes a window for every child process. A guard test fails when a new `child_process` call in the runtime, the scripts or the unit/integration tests omits the option (#843)
