**`http` mode gains an explicit Host allowlist: `--allowed-host <host>` (repeatable) and `MCP_HTTP_ALLOWED_HOSTS` (comma-separated)** — the Streamable HTTP endpoint accepts only loopback `Host` headers (`localhost`, `127.0.0.1`, `[::1]`) as DNS-rebinding protection, which is the right default for a tool that spawns processes and attaches to PIDs, but there was no configuration path at all: a server in a container reached by its service name (`http://mcp-debugger:3001/mcp`) answered 403 with no way to say "another access control fronts this". Operators can now extend the allowlist explicitly. The loopback default is unchanged, there is no wildcard, an unusable entry (a URL, a bare IPv6 literal, `*`) refuses to start by name instead of being dropped, and the effective allowlist is logged at startup.
