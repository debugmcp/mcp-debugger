**Python child processes become child debug sessions under `subProcess: true`** — a Python launch with `dapLaunchArgs.subProcess: true` used to park every child the program spawned until a debugger attached, which the server never did; debugpy's report is now adopted: each child becomes a debug session of its own, listed by `list_debug_sessions` with `parentSessionId`, stopping on the parent's breakpoints (re-sent before it runs), with its own `get_output`, `wait_for_stop` and `close_debug_session`; closing the parent closes its children first. The default stays off until the tree-aware `wait_for_stop` lands (#1005, #1081).
