**The Docker image carries every runtime file an adapter publishes** — the image now copies each adapter package from its own `package.json` `files` field, the same list npm publishes, instead of a hand-maintained list of directories, so a runtime asset added to a package reaches the image as well as npm. The JavaScript adapter's exit-code shim (#796) had been missing from the image because that hand list left it out; the image also gains the JavaScript adapter's `vendor-manifest.json` and the shared package's README (#811, #796)
