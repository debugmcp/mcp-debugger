The Docker image now copies each adapter package from its own `package.json` `files` field, the same list npm publishes, instead of a hand-maintained list of directories. A runtime asset added to a package therefore reaches the image as well as npm. The JavaScript adapter's exit-code shim (#796) had been missing from the image because that hand list left it out. The image gains the files the old list skipped: the JavaScript adapter's `vendor-manifest.json` and the shared package's README.
