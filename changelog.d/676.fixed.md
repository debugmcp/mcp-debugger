**PyPI launcher forwards server flags, and its Docker mode forwards the Host allowlist and publishes on loopback** — `debug-mcp-server` enumerated the options it knew and dropped everything else, so the `--allowed-host` flag added for #667 could not reach the server through the launcher, and in `--docker` mode an exported `MCP_HTTP_ALLOWED_HOSTS` stopped at the container boundary. Any flag after the mode the launcher does not recognise is now passed to the server verbatim, Docker mode forwards `MCP_HTTP_ALLOWED_HOSTS` with `-e` when it is set, and publishes the port on `127.0.0.1` by default (a new `--bind ADDR` chooses another address) — the server's Host allowlist stops browsers, not a direct client that forges `Host: localhost`, so publishing on every interface was real exposure (#676)
