**Go launches report the program's exit code** — Delve never sends a DAP `exited` event and prints the status as one console line, `Process N has exited with status S` (in debug mode only in reply to `disconnect`, so the proxy now sends that request before forwarding `terminated` for adapters that declare it); the Go policy reads the line back and `exitCode` appears in `list_debug_sessions` and the `start_debugging` summary as for every other language, with the line itself still in `get_output` — see the Go README's Exit Code section (#753)
