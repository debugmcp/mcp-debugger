**Java `attach_to_process { processId }`** is refused by name — `'java' does not attach by processId — JDWP has no PID step; start the JVM with -agentlib:jdwp=… and pass that port` — instead of the PID being dropped silently and the JDI bridge failing later with "Port is required"; a Java attach that names neither `port` nor `processId` is refused up front the same way (#895)
