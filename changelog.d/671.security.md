**The deprecated `sse` transport now validates `Host` and `Origin` like `http` does** — `mcp-debugger sse` built a bare Express app with no Host check, so it had none of the DNS-rebinding protection the `http` command gained in #667 and answered any `Host` (and, with `Access-Control-Allow-Origin: *`, any browser page). It now runs the same allowlist middleware first — loopback only by default, the same `--allowed-host` flag and `MCP_HTTP_ALLOWED_HOSTS` variable, the same actionable JSON-RPC 403 — echoes only a validated `Origin` in CORS, and refuses to start on an unusable allowlist entry with the reason on stderr (#671)
