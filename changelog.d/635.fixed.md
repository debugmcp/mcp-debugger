**`set_breakpoint` now tells agents that C/C++ supports function breakpoints and logpoints** — the
tool schema's two language lists omitted C/C++ even though `adapter-policy-cpp.ts` declares
`supportsFunctionBreakpoints` and `supportsLogPoints`, and the C/C++ adapter honors both. Agents
read those descriptions before choosing an addressing mode, so the omission steered them away from
function breakpoints on the one language where source paths are hardest to get right — the
Kubernetes attach flow, where `docs/kubernetes.md` recommends exactly that technique. The agent
skill repeated the omission and the project website inherited it. (#635)
